ESCALATION STRATEGY
================================================================================

1. curl_cffi WITHOUT proxy
   └─> Fastest (0.5-2s), no JS, Chrome TLS fingerprint
   
2. curl_cffi WITH Tor proxy
   └─> Different IP (1-3s), bypasses IP blocks
   
3. Firecrawl WITHOUT proxy
   └─> Full browser (3-8s), JavaScript execution
   
4. Rotate Tor → Firecrawl WITH proxy
   └─> New IP + browser (5-10s), bypasses IP+JS blocks
   
5. FlareSolverr
   └─> Dedicated solver (10-30s), handles Cloudflare challenges
